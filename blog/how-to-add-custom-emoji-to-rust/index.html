Rust にカスタム絵文字を追加する方法

今回はカスタム絵文字 neko.png を追加します。

  1. 次の要件を満たしたカスタム絵文字を準備します。

    • 256*256ピクセルより大きくない
    • .jpgまたは.pngファイル形式であること（注意：.jpgは透過に対応していません）。
    • ファイルサイズが250kb以下であること
    • 8ビットと16ビットのPngが動作しない

  2. カスタム絵文字をサーバーの server/{MY_RUST_SERVER}/serveremoji フォルダにコピーします。

  3. クライアントでサーバーの再接続をおこないます。

  4. チャットに :{FILE_NAME}: を入力するとカスタム絵文字を使用することができます。今回は :neko: と入力します。
