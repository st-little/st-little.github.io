Windows 10 から Windows 11 へ更新する方法

Published on 2025/06/08
Tags windows

概要

Windows 10 を Windows 11 へアップデートした際の手順をまとめました。

Windows 10 の環境（アプリやファイル、設定など）はそのまま引き継がれますが、大事なファイルは念のためバックアップをとっておくことをおすすめします。

Windows 11 のシステム要件を満たしているか確認する

  1. PC 正常性チェック アプリの使用方法 から PC 正常性チェックをインストールします。

  2. PC 正常性チェックを起動し、「Windows 11 のご紹介」の「今すぐチェック」を選択します。

  3. チェック結果が「この PC は Windows 11 の要件を満たしています」と表示されたら、Windows 11 のインストールに進みます。

Windows 11 のインストール

  1. Windows 11 のダウンロード から「Windows 11 インストール アシスタント」をダウンロードします。

  2. 「Windows 11 インストール アシスタント」を起動し、Windows 11 のインストールを開始します。

  3. Windows 11 のライセンス条項に同意して次に進みます。

  4. Windows 11 のダウンロードが始まるので、完了するのを待ちます。

  5. Windows 11 のインストールが完了したら PC を再起動します。

  6. PC が起動したら Windows Update を実施して完了です。
